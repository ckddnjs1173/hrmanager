# 인사야 1.0 법령 버전 관리

> 기준일: 2026-08-14
> 목적: 상담일 기준 최신 법만 적용하는 오류를 방지하고 사건 발생일에 맞는 법령·수치를 선택한다.

## 핵심 결정

인사야는 `현재 연도`를 고정해서 판단하지 않는다.

```text
사용자 사건
→ 사건 발생일(eventDate)
→ 적용 대상 기간
→ 해당 날짜에 유효한 법령 버전 선택
→ 규칙/수치 계산
→ 현재 제도와 달라진 경우 별도 안내
```

현재 `lib/prompt.js`의 2026년 고정 grounding은 과거 사건을 판단할 때 잘못된 법령·수치를 적용할 위험이 있으므로 제품화 과정에서 제거 또는 축소한다.

## Case에 필요한 날짜

- `eventDate`: 해고·체불 등 핵심 사건 발생일
- `periodStart`, `periodEnd`: 임금·근로시간·연차 산정기간
- `employmentStartDate`, `employmentEndDate`
- `asOfDate`: 화면에서 정보를 보여주는 현재 기준일

## Legal Rule 최소 구조

```text
id
category
effectiveFrom
effectiveTo
conditions
value/formula
source
verifiedAt
```

같은 법조문이라도 시행일이 바뀌면 별도 버전으로 관리한다.

## 적용 순서

1. 사건 기준일 확인
2. 사업장 규모 등 적용 조건 확인
3. 해당 날짜에 유효한 Rule 선택
4. 계산 엔진 실행
5. 적용 근거와 기준일을 Case Report에 표시
6. 시행 예정 개정은 계산에 섞지 않고 필요할 때만 별도 안내

## 왜 P0인가

2026-08-14 현재 국가법령정보센터에는 2026-08-20 시행 예정 근로기준법 버전이 존재하고, 연차 관련 추가 개정 중에는 2027-06-10 시행 예정 사항도 존재한다. 따라서 단순한 `2026년 기준` 상수만으로는 제품 신뢰도를 보장할 수 없다.

## 구현 원칙

- AI가 법령 버전을 선택하지 않는다.
- 프롬프트에 법정 수치를 여러 번 하드코딩하지 않는다.
- Calculator와 Legal Rule이 동일한 버전 데이터를 사용한다.
- 과거 사건과 현재 사건에 대한 회귀 테스트를 각각 둔다.
- 화면에 `적용 기준일`과 `근거`를 표시한다.

## 1차 공식 출처

- 법제처 국가법령정보센터
- 고용노동부 노동포털
- 중앙노동위원회

실제 구현 시 각 Rule은 공식 출처 링크와 최종 검증일을 함께 저장한다.
