# 인사야 1.0 핵심 사건 5종

> 제품 흐름 기준 문서. 세부 법률 규칙과 산식은 Legal/Calculator 모듈에서 별도 관리한다.

## 공통 구조

```text
사건 입력
→ 필수 사실 확인
→ 사건 상태 생성
→ 규칙/계산 결과 연결
→ 증거 확인
→ 중요 날짜 확인
→ 다음 행동 제시
→ 문서/공식 절차/전문가 연결
```

## 1. 임금체불

필수 사실:
- 재직/퇴직 상태
- 미지급 항목
- 지급 예정일
- 미지급 기간
- 약정 임금
- 근로시간 자료
- 급여·입금 증거

주요 연결:
- 체불액 계산
- 근로시간·수당
- 연차수당
- 퇴직금 관련 쟁점

완료 상태:
- 금액과 미확인 항목이 정리됨
- 증거 체크가 끝남
- 다음 해결 행동이 정해짐

## 2. 해고·권고사직

필수 사실:
- 회사의 일방 종료인지 사직 권유인지
- 통보일
- 실제 종료일
- 서면 통지 여부
- 입사일
- 사업장 규모 판단 정보
- 사직서 작성 여부

반드시 분리할 판단:
- 해고인가 사직인가
- 해고예고 관련 쟁점이 있는가
- 별도 구제 절차 검토가 필요한가

주요 연결:
- 해고예고 관련 계산
- 마지막 임금
- 퇴직금
- 연차수당

## 3. 퇴직금

필수 사실:
- 입사일
- 퇴사일
- 주당 소정근로시간
- 퇴직 전 임금 자료
- 근로관계 단절 여부
- 퇴직연금 유형
- 중간정산 여부

주요 연결:
- 수급요건 확인
- 계속근로기간
- 평균임금 계산
- 실제 지급액 비교

## 4. 근로시간·수당

필수 사실:
- 실제 출퇴근시간
- 소정근로시간
- 휴게시간
- 야간/휴일근로
- 임금 구성
- 사업장 규모 판단 정보
- 특수 근무제도 여부

주요 연결:
- 실제 근로시간 복원
- 가산수당 계산
- 기지급액 비교
- 미지급 금액이 있으면 임금체불 Case 연결

## 5. 연차

필수 사실:
- 입사일
- 재직/퇴직 상태
- 출근율
- 사용한 연차
- 사업장 규모 판단 정보
- 회사의 연차 관리 기준
- 사용촉진 관련 자료

주요 연결:
- 발생일수 계산
- 사용일수 대조
- 잔여일수
- 연차수당

## 사건 간 연결

하나의 사건에서 여러 쟁점이 생겨도 사용자를 여러 도구로 분산시키지 않는다.

예:

```text
해고 Case
├ 해고 관련 판단
├ 마지막 임금
├ 미사용 연차
└ 퇴직금
```

모두 같은 Case Workspace의 `관련 쟁점`으로 보여준다.

## 구현 순서

1. 임금체불 Vertical Slice
2. 해고·권고사직
3. 퇴직금
4. 근로시간·수당
5. 연차

각 사건이 완성되기 전에는 신규 계산기나 신규 문서 개수를 늘리는 작업을 우선하지 않는다.
