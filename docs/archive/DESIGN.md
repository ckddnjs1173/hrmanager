# 노무AI — 디자인 시스템 & 비주얼 기획서

> 목적: "신뢰감 있는 노무 전문성 + flex.team급 모던 SaaS"를 구현하는 **정식 디자인 시스템**. 토큰·타이포·간격·컴포넌트·페이지 처리·모션·접근성·에셋 비주얼을 규정한다. 구현은 CSS 변수로 매핑한다.

---

## 1. 디자인 원칙 (Design Principles)
1. **신뢰가 먼저** — 법·돈·고용을 다룬다. 절제된 색, 충분한 여백, 명확한 위계. 과한 그라데이션·네온 금지.
2. **대화가 주인공** — 제품의 핵심은 AI 상담. UI는 입력을 방해하지 않는다.
3. **두 개의 얼굴, 하나의 뼈대** — 근로자(차분한 신뢰=블루)·사업주(안정적 전문=딥그린)는 **악센트만 다르고 구조·간격·타이포는 동일**.
4. **여백이 곧 품질** — 섹션 간 큰 호흡(64–96px), 콘텐츠 최대폭 제한.
5. **보여주되 단정하지 않기** — 제품 목업·스크린샷으로 가치를 "보여주고", 카피는 "정보 제공" 톤 유지.

## 2. 컬러 시스템 (Color)

### 2-1. 뉴트럴 램프 (Gray)
| 토큰 | HEX | 용도 |
|---|---|---|
| `--ink-900` | #0B0D12 | 헤드라인 |
| `--ink-700` | #2B2F36 | 본문 강조 |
| `--ink-500` | #4B5563 | 본문 |
| `--ink-400` | #6B7280 | 보조 텍스트(sub) |
| `--ink-300` | #9AA1AD | 플레이스홀더·캡션 |
| `--line` | #E7E9EE | 보더 |
| `--panel` | #F7F8FA | 섹션/카드 배경 |
| `--bg` | #FFFFFF | 기본 배경 |

### 2-2. 브랜드 & 사이트 악센트 (Accent)
시맨틱 토큰 `--accent` / `--accent-soft` / `--accent-ink`를 `body[data-site]`로 스왑.
| 컨텍스트 | accent | accent-soft | accent-ink(텍스트용 진한값) |
|---|---|---|---|
| 기본/AI상담 | #2F6DF6 | #EEF3FF | #1F54C9 |
| 근로자 | #2F6DF6 (블루) | #EEF3FF | #1F54C9 |
| 사업주 | #0F766E (딥그린) | #E7F3F0 | #0B5A53 |

> 규칙: **CTA·링크·강조·활성 상태**는 `--accent`. 본문/구조 색은 뉴트럴 고정. 한 화면에 악센트는 1개 계열만.

### 2-3. 시맨틱 (상태)
| 토큰 | HEX | 용도 |
|---|---|---|
| `--ok` | #22A06B | 양호·완료·체크 |
| `--warn` | #E8A13A | 주의·권장 |
| `--danger` | #E5484D | 위험·금지(✕) |
정보 콜아웃: tip(그린계) / warn(앰버계) / law(악센트계) 3종 고정.

### 2-4. 대비(접근성)
본문 텍스트 대비 ≥ 4.5:1, 큰 텍스트 ≥ 3:1. 악센트 위 흰 텍스트는 두 악센트 모두 통과(블루 4.6:1, 딥그린 5.2:1). `--ink-400`는 14px 이상에서만 사용.

## 3. 타이포그래피 (Type Scale)
- 서체: **Pretendard**(폴백: Apple SD Gothic Neo, Malgun Gothic, system-ui). 숫자·금액은 동일 서체 tnum 권장.
- 스케일(데스크톱 / 모바일):

| 토큰 | size/line/weight/tracking | 용도 |
|---|---|---|
| Display | 47 / 1.2 / 800 / -.035em (모바일 32) | 랜딩 히어로 H1 |
| H1 | 30 / 1.3 / 800 / -.03em (모바일 26) | 페이지 제목 |
| H2 | 33 / 1.25 / 800 / -.03em (모바일 26) | 섹션 제목(fx-h2) |
| H3 | 25–26 / 1.3 / 800 / -.02em | 기능 블록 제목 |
| Title | 16–17 / 1.4 / 700 | 카드 제목 |
| Body-L | 17 / 1.65 / 400 | 히어로 서브 |
| Body | 15 / 1.6 / 400 | 본문 |
| Body-S | 13.5 / 1.55 / 400 | 보조·메타 |
| Caption | 12 / 1.5 / 600 | eyebrow·라벨·태그 |

규칙: 한 페이지 H 레벨은 최대 3단계. 본문 줄길이 ≤ 70자(=콘텐츠 760–800px).

## 4. 간격 · 레이아웃 (Spacing & Grid)
- **4px 베이스, 8px 리듬**. 스케일: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96.
- 섹션 세로 패딩: 데스크톱 60–72px, 모바일 40–46px.
- 컨테이너 최대폭:
  | 종류 | 폭 |
  |---|---|
  | 읽기(글·계산기·요약서) | 760–800px |
  | 그리드(요금제·문서·노무사·랜딩) | 1040–1080px |
  | 채팅 | 760px |
- 그리드: 랜딩 기능 섹션 = 2col(텍스트/비주얼), 카드 = 3col(모바일 1col), 요금제 = 4col(모바일 1col).
- 브레이크포인트: **860px**(데스크톱↔모바일 단일 분기). 보조 560px(요금제/관련글 2→1col).

## 5. 라운드 · 그림자 (Radius & Elevation)
| Radius | 값 | 용도 |
|---|---|---|
| sm | 8–10 | 칩·인풋·작은 버튼 |
| md | 12–14 | 버튼·세그먼트·작은 카드 |
| lg | 16–18 | 카드·목업·콜아웃 |
| xl | 20–24 | CTA 밴드·요금제 카드 |
| pill | 999 | eyebrow·필터 |

| Elevation | 그림자 | 용도 |
|---|---|---|
| e0 | none | 기본 보더 카드 |
| e1 | 0 1px 3px rgba(20,30,60,.04) | 카드 |
| e2 | 0 12px 28px rgba(20,30,60,.08) | 호버·타일 리프트 |
| e3 | 0 34px 70px rgba(20,30,60,.16) | 제품 목업·모달 |

규칙: 그림자는 항상 **차가운 남색 계열 알파**(검정 X)로 떠 보이게. 호버는 `translateY(-3px)` + e2.

## 6. 컴포넌트 스펙 (Components)
각 컴포넌트: 기본/호버/포커스/활성/비활성 상태 규정.

- **버튼**
  - Primary(`btn-fill`): bg `--accent`, 흰 텍스트, radius md, hover brightness .95, focus 2px 악센트 외곽선.
  - Ghost(`btn-ghost`): 흰 bg + 보더, hover 보더·텍스트 악센트.
  - XL(`btn-xl`): 패딩 15×26, 히어로/밴드용.
  - Nav CTA: 작은 fill, 헤더 우측 고정.
- **인풋/검색**: radius sm–md, 포커스 시 보더 악센트. 히어로 검색은 e2 그림자 + 큰 패딩.
- **카드**: 흰 bg, 보더, radius lg, e1. 클릭형(타일)은 hover e2 + 리프트.
- **eyebrow 칩**: caption, 악센트 텍스트 + accent-soft bg, pill.
- **글로벌 바**: 높이 ~56px, 로고+포털 탭(AI상담/근로자/사업주/노무사)+우측 CTA. 스크롤 시 하단 보더 유지.
- **사이트 서브내비**: 글로벌 바 아래 2차 바. 워드마크(점 마크+이름) + 카테고리 + 도구 + 검색. 활성 항목 accent-soft 배경.
- **제품 목업(mock)**: 브라우저 프레임(점3+URL칩) + 바디. e3. 미니 채팅/계산/문서/리스트 변형. 플로팅 배지 1개 허용.
- **콜아웃**: 아이콘+텍스트, 3종 색. 본문 강조용, 한 섹션 1–2개.
- **표**: 헤더 panel bg, 셀 보더, 13.5px.
- **FAQ**: `<details>` 아코디언, +/− 인디케이터.
- **배지/태그**: 출처(공공데이터/직접등록), 상태(오늘 상담가능=ok), 자격확인=ok.
- **푸터**: panel bg, 4컬럼 링크맵 + 법적 고지 + 카피. 콘텐츠 끝에서 스크롤.

## 7. 페이지별 디자인 처리 (Page Treatments)
| 페이지 | 핵심 비주얼 처리 |
|---|---|
| **AI 상담(홈)** | 미니멀. 중앙 인사(Display 축소)+큰 입력창(e2)+제안칩. 채팅 전환 시 버블 대비. 배경 무지/미세 그라데이션. |
| **근로자/사업주 랜딩** | 히어로 split(텍스트+제품 목업), 페인포인트 3카드, 기능 교차 3섹션(alt 배경), 카테고리 그리드, 다크 CTA 밴드. |
| **카테고리 인덱스** | 빵부스러기+eyebrow+H1, 대표 가이드 핀(좌측 악센트 바), 글 리스트, 도구 버튼, FAQ. |
| **정보글** | 760px 읽기 폭. 감수 메타바, 콜아웃, 자동 목차, 표, FAQ, 관련글, 공유. 사이트 악센트. |
| **계산기** | 세그먼트(알약)+폼+결과 카드(accent-soft, 금액 Display급). |
| **노무사 찾기** | 와이드. 필터칩+카드 리스트(아바타·태그·출처). 프로필 상세는 2col(정보/예약). |
| **문서센터** | 와이드 3col 타일 → 폼 → 초안 미리보기(문서 목업 톤). |
| **요금제** | 와이드 4col, 인기 플랜 악센트 보더+그림자. |
| **상담요약서** | 문서형 카드, 점선 구분, 마스킹 표시. |

## 8. 아이콘 · 일러스트 · 미디어 방향
- **아이콘**: 1차는 이모지(빠른 운영). 2차 통일 시 라인 아이콘 세트(2px stroke, 라운드 캡, 단색=ink-500/accent). `assets/icons/<key>.svg`.
- **일러스트**: 과한 3D·스톡 금지. 절제된 플랫 + 악센트 1색 포인트. 작동방식·빈 상태용.
- **제품 스크린샷**: 히어로/기능 섹션의 핵심. 실제 화면을 **목업 프레임**에 담아 e3. 에셋 교체 슬롯 `assets/<site>/hero-shot.png`.
- **사진**: 노무사 프로필만(정사각, 중앙 크롭). 없으면 이니셜 아바타(accent-soft).
- **OG 이미지**: 1200×630, 좌측 제목+우측 미니 목업/로고, 사이트 악센트 배경. `assets/og/<key>.png`.

## 9. 모션 (Motion)
- 원칙: **빠르고 은은하게**. 과한 패럴랙스 금지.
- 듀레이션: 마이크로 120–160ms, 전환 200–260ms. 이징 `cubic-bezier(.2,.7,.2,1)`.
- 패턴: 카드 hover 리프트, 화면 전환 fade+6px up(기존 `@keyframes fade`), 타이핑 인디케이터, 스크롤 진입 시 섹션 8–12px fade-in(IntersectionObserver, prefers-reduced-motion 존중).
- 접근성: `prefers-reduced-motion: reduce` → 모든 트랜지션/자동재생 비활성, 히어로 영상 일시정지.

---

## 10. 접근성 (Accessibility)
- 명도 대비(§2-4) 준수. 포커스 링: 2px `--accent` + 2px 오프셋, 항상 가시.
- 키보드: 모든 인터랙션 tab 도달, `<details>`/버튼 시맨틱. 모달/드로어 focus trap.
- 영상: 무음·자동재생은 장식용만, 컨트롤 불요지만 reduced-motion 시 정지.
- 폼: label 연결, 에러 텍스트+색 동시. 색만으로 의미 전달 금지(✓/⚠ 아이콘 병기).
- 대체텍스트: 정보성 이미지 alt, 장식 이미지 `alt=""`.

---

## 11. 보이스 & 카피 톤 (UX Writing)
- 짧고 단정적이지 않게. "~일 수 있습니다 / 추정 / 확인이 필요합니다".
- 헤드라인은 사용자 언어(돈·해고·계약), 기능명은 명사형.
- 항상 면책 1줄. 금액엔 "(추정)". 노무사는 "추천"❌ → "정보 제공/검색".

---

## 12. 구현 매핑 & 다음 단계
- 현재 ad-hoc 토큰 → 위 토큰 체계로 **CSS 변수 정리**(:root + body[data-site]). 뉴트럴 램프(`--ink-*`) 도입.
- 타입/간격/라운드/그림자 스케일을 변수화해 일관 적용.
- 컴포넌트 상태(hover/focus/disabled) 누락분 보강 + 포커스 링 전역.
- 스크롤 진입 모션(IO) + reduced-motion 가드 추가.
- 다크모드는 v2 과제(토큰 체계가 있으면 확장 용이).

> 이 문서가 디자인의 단일 기준(source of truth). 신규 화면/컴포넌트는 여기 토큰·스케일·상태 규칙을 따른다.
