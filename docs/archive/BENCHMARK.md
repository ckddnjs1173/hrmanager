# BENCHMARK.md — 인사야 벤치마크 기획본

> 잘하는 제품에서 "지금 훔칠 만한 요소"만 골라 인사야 적용안·우선순위로 정리한 문서.
> 상태 범례: ✅ 적용됨 · 🔶 제안 · ⭐ 최우선. (시각본 시안은 Artifact로 별도 공유)

노무 = **어렵고 무섭게 느껴지는 주제 + 신뢰가 생명 + AI 제품**. 이 성격에 맞는 레퍼런스를 벤치마크했다.

---

## A. 카피·보이스 — 토스 8원칙

토스는 "복잡한 금융을 쉽고 친근하게" 만드는 [8가지 라이팅 원칙](https://toss.tech/article/8-writing-principles-of-toss)으로 신뢰를 쌓았다. 인사야의 **가장 저비용·고효과** 개선점.

| 원칙 | 요지 | 인사야 적용 |
|---|---|---|
| 1 예측 가능한 힌트 | 버튼이 다음 화면을 예고 | CTA를 결과 예고형으로 ("가이드 둘러보기"→"3분 요약부터 보기") |
| 2·3 잡초/빈 문장 제거 | 스캔되는 짧은 문장 | 면책·안내문 절반 길이로 |
| 4 핵심 메시지 집중 | 지금 필요한 정보만 | 한 화면 = 한 메시지·한 CTA |
| 5·7 말하기 쉬운·모두의 말 | 전문용어 순화 | 노무 용어(진정·소멸시효…)에 툴팁 1줄 |
| 6 강요하지 않기 | 공포 대신 중립 사실 | "분쟁이 되기 전에"→"3분 점검으로 미리 대비해요" |
| 8 감정에 공감 | 거래 아닌 '내 편' | 진단 상단 "혼자 판단하기 어려운 문제예요. 같이 정리해요" |

공통: **해요체 · 능동형 · 긍정형** 일관.

**Before → After 예시**
- 면책: "AI 답변은 법률·노무 자문이 아닌 정보 제공입니다…" → "여기 답변은 참고용 정보예요(자문 아님). 주민번호·계좌·실명은 적지 마세요."
- 사업주 히어로: "노무 리스크, 분쟁이 되기 전에 점검하세요" → "직원 한 명이라도 있다면, 3분 점검으로 미리 대비해요"

## B. 제품·인터랙션 — Linear·Notion·Perplexity·involve.me

"말하지 말고 보여주고, 만지게 하라" (2026 패턴).

| 요소 | 출처 | 상태 | 적용 |
|---|---|---|---|
| 설명가능 AI (근거+신뢰라벨) | Perplexity | ✅ | 진단에 "이렇게 봤어요+근거 법조항+[가능성]" |
| 인터랙티브 데모 히어로 | involve.me·Linear | ⭐ | 히어로를 실제 입력되는 미니 진단(3문항)으로 |
| 벤또 제품 오버뷰 | Vercel·Raycast | ✅ | '제품 한눈에' 벤또 |
| 스티키 단일 CTA | 모던 SaaS | 🔶 | 스크롤 따라오는 "무료 진단" 바 |
| 절제된 마이크로 모션 | Linear·토스 | ✅ | 스크롤 리빌·숫자 카운트업·도넛 |
| 빈/로딩 상태에 개성 | 뉴닉·토스 | 🔶 | 마스코트 + "법령 살펴보는 중" |

## C. 콘텐츠·카드뉴스 — 뉴닉·어피티

카드뉴스는 일반 광고 대비 **10배 효과**, MZ 최애 포맷.

| 요소 | 출처 | 상태 | 적용 |
|---|---|---|---|
| 브랜드 마스코트 | 뉴닉 고슴도치 | ⭐ | '인사야' 라인 캐릭터 → 카드뉴스·빈상태·로딩·요약서 |
| 3분 카드요약 | 카드뉴스 통계 | ✅ | 18개 가이드 자동 카드뉴스 |
| 독자 눈높이 카피 | 어피티 페르소나 | ✅ 부분 | 근로자/사업주 분기 → 화자 톤 강화 |
| "이 글 도움됐나요?" | 뉴닉 쌍방향 | 🔶 | 👍/👎 위젯 (feedback 테이블 이미 존재 → 백엔드 추가 0) |

## D. 계산기 UX — 핀테크

정석: **슬라이더 입력 · 실시간 결과 · 시각 브레이크다운 · 공유 리포트**.

| 요소 | 상태 | 적용 |
|---|---|---|
| 실시간 재계산 | 🔶→✅ | 입력 즉시 결과 갱신 |
| 시각 브레이크다운 | 🔶→✅ | 결과를 스택 바/도넛으로 구성 분해(실수령 vs 공제 등) |
| 결과 카운트업 | ✅ | 금액 0→목표 |
| 공유·문서 연결 | ✅ | 결과 복사·인쇄·요약서·노무사 |

## E. 최우선 3가지 (효과/비용)

1. **토스식 카피 패스** — 전 화면 8원칙 리라이트 + 용어 툴팁. *코드 위험 0, 신뢰·전환 즉효.*
2. **인사야 마스코트** — 라인 캐릭터 1종 → 카드뉴스·빈상태·로딩·요약서. *무자본 브랜드 각인.*
3. **계산기 리포트화** — 실시간·브레이크다운·공유. *핵심 전환 도구를 제품답게.*
