# 콘텐츠 인벤토리 & 비주얼 콘텐츠 기획서

> 두 가지를 정의한다. **(1) 무엇을 넣을지**(문서·가이드·도구 전체 목록) **(2) 어떻게 보여줄지**(큼직·친근·전문, 텍스트 최소·도형/표/숫자 최대).
> 톤: **전문적이되 친근하게**. 위압적인 법률 문서 느낌 ❌ → 큰 숫자·아이콘·색 블록·표·단계도로 "한눈에 이해". 단, 신뢰를 해치는 유치함은 ❌(둥글고 큼직하고 깔끔한 "친근한 전문가").

## 3. 도구·인터랙티브 콘텐츠
- 계산기(확장): 퇴직금·주휴·해고예고·연차·연장/야간/휴일 + 최저임금위반점검·실업급여·통상임금·4대보험/실수령.
- **자가진단 플로우**: "내가 받을 수 있나?" Yes/No 분기형 인터랙티브(예: 부당해고 해당 여부).
- **체크리스트**: 증거 체크리스트, 해고 전 체크, 진정 준비물(체크형 UI, 진행률).
- **용어사전**: 통상임금·평균임금·소정근로 등 카드형 풀이.
- **사례·판례 요약** 카드.

# PART 2. 비주얼 콘텐츠 디자인 (큼직·친근·전문)

## 4. 표현 원칙
- **텍스트 < 비주얼**: 한 문단으로 쓸 걸 → 숫자 카드·표·단계도·아이콘 리스트로.
- **큼직큼직**: 큰 제목, 큰 숫자, 큰 아이콘, 넉넉한 패딩(card 24~28), 라운드 크게(16~24).
- **한눈에**: 글 상단 "한 장 요약" + 스크롤하며 시각 블록으로 이해.
- **친근**: 부드러운 악센트 톤·둥근 형태·짧고 다정한 문장, 절제된 일러스트/아이콘 포인트(유치하지 않게).
- **신뢰**: 숫자엔 근거(조항), 색만으로 의미 금지(아이콘+텍스트).

## 5. 콘텐츠 블록 라이브러리 (재사용 컴포넌트)
가이드·문서·카테고리·계산기에서 공통으로 쓰는 "시각 블록".

**(a) TL;DR 요약 카드** — 글 맨 위, 핵심 3개를 큰 카드로
```
┌───────────────── 한 장 요약 ─────────────────┐
│  💰 받을 수 있어요   ⏳ 시효 3년   📄 무료 신고 │
│  3개월치 임금·지연이자  놓치면 청구 불가  노동청 │
└──────────────────────────────────────────────┘
```

**(b) 큰 숫자 하이라이트** — 핵심 수치를 크게
```
[ 3년 ]  임금채권 소멸시효     [ 30일 ]  해고예고
[ 10,320원 ] 2026 최저시급
```

**(c) 단계 플로우(Stepper)** — 절차를 1·2·3 도형으로(텍스트 대신)
```
①증거정리 → ②노동청 진정 → ③조사 → ④지급/소송
```

**(d) 비교 표/카드** — 헷갈리는 개념 나란히
```
권고사직 | 해고 | 계약만료
합의종료  | 일방  | 기간종료
구제신청 X | O    | 원칙 X
```

**(e) 자가진단(분기) 위젯** — Yes/No 눌러 결론
```
5인 이상? ─예→ 서면통지 받음? ─아니오→ 부당해고 쟁점 ↑
```

**(f) 체크리스트 카드** — 탭하며 진행률
```
☑ 근로계약서  ☑ 급여명세서  ☐ 출퇴근기록  (2/3)
```

**(g) 계산기 임베드** — 글 안에서 바로 계산("내 금액 보기")

**(h) 콜아웃 3종** — 💡팁 / ⚠️주의 / ⚖️근거(조항)

**(i) 아이콘 리스트** — 불릿 대신 아이콘+한 줄

**(j) 타임라인** — 기한 시각화(해고일 → 3개월 → 구제신청 마감)

**(k) FAQ 아코디언** · **(l) 관련글·문서 카드** · **(m) 인용/사례 카드**

## 6. 글(가이드) 새 레이아웃 (텍스트↓ 비주얼↑)
```
[감수 메타]  
[H1 큰 제목]  
(a) TL;DR 요약 카드 ← 큼직
(b) 큰 숫자 하이라이트
"이런 경우인가요?" (e) 자가진단 위젯
핵심 내용 = (c)단계 + (d)비교표 + (i)아이콘리스트 (문단 최소)
(g) 계산기 임베드  /  (f) 체크리스트
(h) 콜아웃(주의·근거)
(k) FAQ → (l) 관련글/문서 → CTA
```
규칙: 한 화면(스크롤 1뷰)에 **시각 블록 1~2개**. 긴 문단 금지(3줄 내), 나머지는 블록으로.

## 7. 문서센터 새 화면 (큼직 타일·그룹)
- 상단: "무엇을 만들까요?" 큰 검색 + 사용자유형 토글(근로자/사업주).
- **그룹 카드**: 「채용·계약」 「해고·징계」 「임금」 「증명·기타」 「근로자 대응」 — 그룹 안에 큰 아이콘 문서 타일.
- 문서 타일: 큰 아이콘 + 제목 + "표준양식" 배지 + 1줄 설명. hover 리프트.
- 인기/추천 문서 상단 노출, "상황별 문서팩" 묶음 카드.

## 8. 카테고리 인덱스 새 화면
- 헤더: 큰 아이콘 + 카테고리명 + 1줄 + (배너 슬롯).
- "이 주제 핵심" 숫자 카드 3개(b).
- 대표 가이드 핀(큰 카드) → 글 리스트(아이콘 행) → 관련 계산기/문서 → FAQ.

## 9. 친근·전문 비주얼 토큰(디자인 시스템 연계)
- 라운드: 카드 `--r-lg~xl`(16~20), 강조 카드 `--r-2xl`(24).
- 숫자 하이라이트: Display급(40~56) 800, 악센트 색.
- 아이콘: 큰 라인/이모지(섹션 통일), 색 블록 배경(accent-soft 원형).
- 색: 뉴트럴 베이스 + 악센트 포인트, 상태색은 의미블록에만.
- 일러스트(선택, 절제): 빈 상태·자가진단·단계도에 플랫 1색 포인트.
- 모션: 카드 hover 리프트, 숫자 카운트업(절제), 스크롤 진입(기존).

## 10. 작업 방식(데이터 구조)
- 글 = "블록 배열" 데이터로(문단/요약/숫자/단계/비교표/체크/FAQ 타입) → 렌더러가 시각 블록으로 출력. (현 inline 문자열 → 구조화)
- 문서 = 양식 모듈(표준양식 기반) + 메타(그룹·표준여부).
- 새 블록은 §5 라이브러리에서만(일관성).

## 11. 실행 순서(제안)
1. **블록 라이브러리 구현**(§5) + 글 데이터 구조화(§10) — 토대.
2. **글 레이아웃 전환**(§6): 기존 12편을 TL;DR·숫자·단계·표 중심으로 리디자인.
3. **콘텐츠 확장**(§2): 카테고리별 글 추가(우선 임금체불·부당해고·퇴직금 계열).
4. **문서센터 확장·리디자인**(§1,§7): 표준양식 문서 추가 + 그룹 큼직 타일 + 문서팩.
5. **자가진단·체크리스트·용어사전**(§3) 추가.
6. 카테고리 인덱스 비주얼화(§8).
