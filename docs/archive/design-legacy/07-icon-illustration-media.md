# 디자인 상세 기획 ⑦ 아이콘 · 일러스트 · 미디어

> 시리즈 7/N. 원칙: **절제된 비주얼이 신뢰를 만든다.** 스톡 이미지·과한 3D·무지개 그라데이션 금지. 핵심 비주얼은 "제품 스크린샷". 모든 에셋은 폴백이 있어 비어도 깨지지 않는다.

---

## 1. 아이콘 (Icons)

### 1-1. 2단계 전략
- **1차(현재·운영 속도)**: 이모지(💰⚖️📄🕐😟📝🏛️…). 빠르고 무료, 한글 UI에 자연스러움. 카테고리·타일·콜아웃·페인포인트에 사용 중.
- **2차(브랜드 통일)**: **라인 아이콘 세트**로 교체 → 더 전문적·일관적. 슬롯 `assets/icons/<key>.svg`. 있으면 우선, 없으면 이모지 폴백.

### 1-2. 라인 아이콘 규격(2차)
| 항목 | 기준 |
|---|---|
| 스타일 | 라인(아웃라인), 채움 없음. 라운드 캡/조인 |
| stroke | 1.75–2px (24px 그리드 기준) |
| 그리드 | 24×24 박스, 1.5px 패딩 |
| 색 | 단색. 기본 `--ink-500`, 활성/강조 `--accent` |
| 크기 토큰 | 16(인라인)·20(버튼/리스트)·24(타일)·28+(히어로) |
| 포맷 | SVG(`currentColor` 사용 → 색은 CSS로) |
| 라이브러리 후보 | Lucide(권장: 일관·MIT·라운드) 또는 자체. 한 세트만 |

규칙: 한 화면에서 라인↔이모지 혼용 금지(섹션 단위 통일). 의미 전달 아이콘엔 텍스트 라벨 병기.

### 1-3. 아이콘 색·상태
- 기본 ink-500, 호버/활성 accent, 비활성 ink-300.
- 상태 아이콘(✓ ok / ⚠ warn / ✕ danger)은 시맨틱 색 + 반드시 텍스트 병기.

---

## 2. 일러스트 (Illustration)
- **톤**: 미니멀 플랫. 뉴트럴 + **악센트 1색 포인트**. 디테일·그림자 최소. 사람은 추상적/표정 절제.
- **용도**: 빈 상태, 작동 방식 단계, 온보딩, 404. 마케팅 히어로는 일러스트보다 **제품 목업** 우선.
- **금지**: 스톡 사진형 3D, 무지개/네온 그라데이션, 과장된 캐릭터, 클립아트.
- 슬롯: `assets/worker/step-1~3.svg`, `assets/employer/step-1~3.svg`. 없으면 번호 배지(현 디자인)로 대체.
- 포맷: SVG(색 토큰화 가능하면 베스트), 또는 가벼운 PNG/WebP.

---

## 3. 제품 스크린샷 / 목업 (Product Mock) — 핵심 비주얼
- 마케팅의 주인공. 실제 화면을 **브라우저 프레임 목업**에 담아 `--e3`로 띄움(⑤ 참조).
- **CSS 목업이 기본**(에셋 없이도 "제품"처럼 보임) + **이미지 슬롯**으로 교체:
  - 히어로: `assets/<site>/hero-shot.png` (목업 위에 덮어 표시, 없으면 CSS 목업)
  - 권장 규격: 가로형, 실제 UI 캡처, **2배 해상도(@2x)**, 여백 최소, 라운드는 프레임이 처리.
- 캡처 가이드: 실제 데이터처럼 보이되 **민감정보 마스킹**(회사명/실명 ***), 금액은 예시값.
- 동영상 데모(선택): 짧은 화면 녹화 루프(무음). 슬롯 `assets/<site>/hero.webm`+`.mp4`+`hero-poster.jpg`.

---

## 4. 사진 (Photography) — 노무사 프로필만
- 사용처: **노무사 프로필 사진만**(그 외 인물 스톡 금지).
- 규격: 정사각 **400×400**, 중앙 크롭, 인물 상반신, 밝은 배경.
- 폴백: 없으면 **이니셜 아바타**(accent-soft bg + accent 텍스트, 800). 절대 깨진 이미지 노출 금지(`onerror`로 이니셜 대체).
- 슬롯: `assets/nomusa/<id>.jpg`.

---

## 5. 로고 / 브랜드 마크
- 로고: `assets/brand/logo.svg`(가로형, 높이 ~26px 기준). 로드 실패/없음 → **텍스트 워드마크**("노무**AI**") 폴백.
- 사이트 워드마크: "근로자노무"(블루)·"사업주노무"(딥그린) — 서브내비. 점 마크(accent 원) + 텍스트.
- 파비콘: `assets/brand/favicon.png`(256×256). 없으면 브라우저 기본.
- 여백 규칙: 로고 주변 보호 여백 = 로고 높이의 0.5배.

---

## 6. OG / 소셜 공유 이미지
- 규격: **1200×630**(OG/Twitter summary_large 호환).
- 템플릿: 좌측 **제목(2~3줄, ink-900, 800)** + 우측 **미니 목업/로고** + 하단 "노무AI" 워드마크. **사이트 악센트 배경 틴트**(근로자 블루 / 사업주 딥그린).
- 글마다: `assets/og/<key>.png`. 없으면 공통 `assets/brand/og-default.png`. 정적 페이지 `<meta property="og:image">`로 연결.
- 안전영역: 가장자리 60px 패딩(플랫폼 크롭 대비).
- 카카오톡 공유 고려(국내) — 동일 OG 태그 사용, 1200×630 권장.

## 7. 미디어 폴백 & 파이프라인 (안 깨지는 규칙)
| 에셋 | 있을 때 | 없을 때(폴백) |
|---|---|---|
| 히어로 영상 | `<video>` 자동재생 | 포스터 이미지 → 그라데이션 |
| 히어로 스크린샷 | 이미지 표시 | CSS 제품 목업 |
| 로고 | 이미지 | 텍스트 워드마크 |
| 노무사 사진 | 이미지 | 이니셜 아바타 |
| 타일 아이콘 | SVG | 이모지 |
| OG 이미지 | 글별 png | 공통 og-default |
| 일러스트 | SVG | 번호 배지/아이콘 |

구현 패턴:
- `<img onerror="this.remove()/이니셜로 교체">`, `<video onerror="this.remove()">`.
- 영상: `<video autoplay muted loop playsinline poster=...>` + `<source webm><source mp4>`.
- 이미지: `loading="lazy"` + 명시적 `width/height`(CLS 방지), WebP 우선.
- 절대 깨진 이미지 아이콘(broken)을 사용자에게 노출하지 않는다.

### 최적화
- 포맷: 사진=WebP/JPG, 로고/아이콘/일러스트=SVG, 스크린샷=WebP(또는 PNG @2x).
- 용량: 히어로 영상 <5MB, 이미지 적정 압축. `loading="lazy"`·`decoding="async"`.
- 반응형 이미지: 필요 시 `srcset`(@1x/@2x).

---

## 8. 에셋 명명 규칙 (Naming)
- 소문자·하이픈, 키 기반: `hero.mp4`, `hero-poster.jpg`, `hero-shot.png`, `cat-wage.jpg`, `og/<key>.png`, `nomusa/<id>.jpg`, `icons/<key>.svg`, `brand/logo.svg`.
- 폴더는 `assets/<도메인>/`(brand·worker·employer·og·nomusa·icons·guides) — `assets/README.md` 매니페스트와 일치.

---

## 9. Do / Don't
- ✅ 핵심 비주얼은 제품 목업/스크린샷
- ✅ 아이콘 한 세트(라인) 또는 이모지 — 섹션 단위 통일
- ✅ 모든 미디어에 폴백(안 깨짐)
- ✅ 스크린샷은 민감정보 마스킹·@2x
- ✅ OG 1200×630·안전영역·사이트 악센트
- ❌ 스톡 인물 사진·3D·무지개 그라데이션
- ❌ 깨진 이미지 아이콘 노출
- ❌ 라인↔이모지 한 화면 혼용
- ❌ 무거운 영상/이미지 무압축
