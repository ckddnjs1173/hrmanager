# 디자인 상세 기획 ④ 라운드 · 그림자(Elevation)

> 시리즈 4/N. 원칙: **부드럽되 과하지 않게**. 라운드는 일관 스케일, 그림자는 "차가운 남색 빛"으로 은은하게 떠 보이게(검정 그림자 금지). 깊이는 의미가 있을 때만(목업·모달·호버).

---

## 1. 라운드 스케일 (Radius)
| 토큰 | px | 용도 |
|---|---|---|
| `--r-sm` | 8 | 인풋, 작은 버튼, 태그 안쪽, 코드칩 |
| `--r-md` | 12 | 버튼, 세그먼트, 작은 카드, 콜아웃 |
| `--r-lg` | 16 | 기본 카드, 타일, 목업, 글 콜아웃 |
| `--r-xl` | 20 | 요금제 카드, 큰 패널 |
| `--r-2xl` | 24 | CTA 밴드, 히어로 목업(강조) |
| `--r-pill` | 999 | eyebrow·필터·칩·세그먼트(알약) |
| `--r-full` | 50% | 아바타·점 마크·아이콘 원형 |

규칙: 같은 위계의 요소는 같은 라운드. **작을수록 작은 라운드**(아이콘<버튼<카드<밴드). 사각(0)은 표 셀·풀블리드 배경 정도만.

---

## 2. 중첩 라운드 (Nested radius)
바깥 카드 안에 또 카드/이미지가 있을 때 동심원 유지:
```
inner-radius ≈ outer-radius − inner-padding
```
- 예: 카드 `--r-lg`(16) + 패딩 16 → 안쪽 이미지/서브카드 `--r-sm`(8)~`--r-md`.
- 목업의 바깥 프레임 `--r-lg`(18) → 내부 바디는 동일 프레임이 자르므로 별도 라운드 불필요(overflow:hidden).
- 꽉 차게 들어가는 미디어는 부모 라운드를 따르도록 `overflow:hidden` 또는 동일 radius.

---

## 3. 엘리베이션 스케일 (Elevation / Shadow)
**2-레이어**(앰비언트 작은 그림자 + 방향성 큰 그림자)로 자연스럽게. 색은 `rgba(20,30,60, α)` 고정(차가운 남색).

| 토큰 | box-shadow | 용도 |
|---|---|---|
| `--e0` | `none` (보더로만 구분) | 정적 카드 기본·표·입력 |
| `--e1` | `0 1px 2px rgba(20,30,60,.04), 0 1px 3px rgba(20,30,60,.05)` | 살짝 떠야 하는 카드, 드롭다운 트리거 |
| `--e2` | `0 6px 16px rgba(20,30,60,.06), 0 12px 28px rgba(20,30,60,.08)` | **호버 리프트·클릭형 타일·검색바** |
| `--e3` | `0 12px 28px rgba(20,30,60,.10), 0 34px 70px rgba(20,30,60,.16)` | **제품 목업·모달·플로팅 카드** |
| `--e-float` | `0 18px 44px rgba(20,30,60,.15)` | 목업 위 떠있는 배지 |
| `--e-modal` | `0 24px 60px rgba(11,13,18,.28)` | 모달/다이얼로그(scrim과 함께) |

규칙:
- **그림자는 의미가 있을 때만**. 본문·일반 카드는 `--e0`(보더)로 충분. 남발 금지.
- 그림자 색은 항상 차가운 남색 알파(검정·회색 그림자 금지 → 탁해 보임).
- 위로 뜰수록 그림자 **더 크고 더 흐리게**(blur↑, 퍼짐↑, 알파는 과하지 않게).

---

## 4. 컴포넌트 → 라운드/그림자 매핑
| 컴포넌트 | radius | elevation(기본 / hover) |
|---|---|---|
| 인풋·검색(일반) | `--r-sm`~`--r-md` | e0 / 포커스=링 |
| 히어로 검색바 | `--r-md` | **e2** |
| 버튼(채움/고스트) | `--r-md` | e0 / 미세(없음~e1) |
| 칩·필터·eyebrow | `--r-pill` | e0 |
| 세그먼트(계산기 탭) | `--r-pill` | e0 |
| 카드(정적) | `--r-lg` | **e0**(보더) / — |
| 타일(클릭형: 카테고리/문서/주제) | `--r-lg` | e0 / **e2 + translateY(-3px)** |
| 요금제 카드 | `--r-xl` | e0 / 인기=e2 |
| 제품 목업 프레임 | `--r-lg`(18) | **e3** |
| 목업 위 플로팅 배지 | `--r-md`(14) | `--e-float` |
| 콜아웃 | `--r-lg` | e0 |
| CTA 밴드(다크) | `--r-2xl`(24) | e0(자체가 강조) |
| 모달/드로어 | `--r-xl`(상단만 모바일) | `--e-modal` |
| 아바타·점 마크 | `--r-full` | e0 |
| 표 | 0(셀) / 컨테이너 `--r-lg` | e0 |

---

## 5. 호버/인터랙션 깊이 규칙
- **클릭형 타일**: 기본 e0 → hover `transform:translateY(-3px)` + `--e2`. 트랜지션 140–160ms.
- **버튼**: 깊이 변화보다 색(밝기) 변화 우선. 채움 버튼 hover=`filter:brightness(.95)`, active=`translateY(1px)`.
- **카드(정적 정보)**: 호버 깊이 없음(클릭 불가한데 떠오르면 혼란).
- **포커스는 그림자가 아니라 링**(§7) — 그림자와 분리.
- 눌림(active): `translateY(1px)` + 그림자 한 단계↓.

---

## 6. 보더 vs 그림자 — 사용 기준
| 상황 | 선택 |
|---|---|
| 흰 배경 위 흰 카드 구분 | **보더(`--line`)** 우선, 필요 시 e1 |
| panel 배경 위 흰 카드 | 보더 또는 e1(배경 대비로 이미 구분됨) |
| 진짜 "떠 있는" 요소(목업·드롭다운·모달) | **그림자(e2~e3)** |
| 호버로 들어올림 | 그림자 e2 + translateY |
규칙: 평면 위계는 보더·배경색으로, 공간 위계(떠 있음)는 그림자로. 둘 다 과하게 겹치지 않기.

---

## 7. 포커스 링 (그림자 아님)
- `:focus-visible{ outline:2px solid var(--accent); outline-offset:2px; }`
- 그림자형 링이 필요하면 `box-shadow:0 0 0 3px <accent>40` (그러나 elevation 그림자와 동시 사용 시 합성 주의).
- 모든 인터랙티브 요소에 가시적 포커스 필수(접근성). 라운드 따라 outline도 둥글게(브라우저 기본).

---

## 8. 다크 모드 그림자 (v2)
- 다크 배경에선 남색 알파 그림자가 잘 안 보임 → **알파↑ + 검정 기반**으로 전환하고, 보더(밝은 라인)로 보강.
- e3(목업) 다크: `0 20px 50px rgba(0,0,0,.5)` + 1px 밝은 보더.
- 토큰만 미리 잡고 v2에서 교체.

---

## 9. 구현 — CSS 토큰

```css
:root{
  --r-sm:8px; --r-md:12px; --r-lg:16px; --r-xl:20px; --r-2xl:24px;
  --r-pill:999px; --r-full:50%;
  --e0:none;
  --e1:0 1px 2px rgba(20,30,60,.04), 0 1px 3px rgba(20,30,60,.05);
  --e2:0 6px 16px rgba(20,30,60,.06), 0 12px 28px rgba(20,30,60,.08);
  --e3:0 12px 28px rgba(20,30,60,.10), 0 34px 70px rgba(20,30,60,.16);
  --e-float:0 18px 44px rgba(20,30,60,.15);
  --e-modal:0 24px 60px rgba(11,13,18,.28);
  --ease:cubic-bezier(.2,.7,.2,1);
}
.card{border:1px solid var(--line);border-radius:var(--r-lg);box-shadow:var(--e0)}
.tile{border:1px solid var(--line);border-radius:var(--r-lg);transition:transform .15s var(--ease),box-shadow .15s var(--ease),border-color .15s}
.tile:hover{transform:translateY(-3px);box-shadow:var(--e2);border-color:var(--accent)}
.mock{border-radius:var(--r-lg);box-shadow:var(--e3);overflow:hidden}
.cta-band{border-radius:var(--r-2xl)}
.btn:active{transform:translateY(1px)}
```

> 기존 ad-hoc `box-shadow:0 34px 70px...` 등을 `--e3` 등으로, `border-radius` 숫자들을 `--r-*`로 치환.

---

## 10. Do / Don't
- ✅ 라운드는 스케일에서만, 작을수록 작게
- ✅ 그림자는 차가운 남색 알파·2레이어
- ✅ 떠 있는 것에만 그림자(목업·모달·호버)
- ✅ 중첩 시 동심원(inner = outer − padding)
- ❌ 검정/회색 그림자(탁함)
- ❌ 정적 정보 카드에 큰 그림자·호버 리프트
- ❌ 포커스를 그림자로만 표현(outline 필수)
- ❌ 한 요소에 라운드 값 제각각
