## 1. 홈 (`/`) — 토스

- **적용 구조**: 인사말 한 줄 → 원형 숏컷 5개(라벨만) → 세로 피드.
- **체크리스트**: 5/5 아니오 → **통과**.
  - 1차 시도에서 피드 항목이 "색깔 사각형 아이콘 + 텍스트" 반복 패턴(체크리스트 3번)이었음 → 아이콘을 없애고 첫 항목은 큰 숫자(1,166명, tabular-nums), 나머지는 kicker+헤드라인 타이포 위계로 재작성해 통과.
- **스크린샷**: `.claude/design-refs/2026-09-07/01-home.png`
- **시도 횟수**: 2회(1회 실패 → 수정 → 통과)

## 2. AI 상담 (`/` → AI상담 클릭) — Perplexity

- **적용 구조**: 중앙 검색창 하나 + 추천 pill 6개, 사이드바/말풍선 나열 없음.
- **체크리스트**: 5/5 아니오 → **통과**.
  - 추천 pill(999px)은 레퍼런스가 명시적으로 요구하는 요소라 1번 항목의 "습관적 반복"에는 해당하지 않는다고 판단.
  - 이전 세션에 있던 상시 사이드바+피드 잔존 버그(`!important` 충돌)는 이미 수정됨(재확인만).
- **스크린샷**: `.claude/design-refs/2026-09-07/02-ai-consult.png`
- **시도 횟수**: 1회 통과(이전 세션에서 이미 고쳐둔 상태 재확인)

  - 상단에 kicker+h1+sub는 있지만 곧바로 검색바/체크박스/리스트로 이어져 "헤드라인+버튼+카드그리드" 뼈대와는 다름.

## 4. Case 워크스페이스 (임금체불/퇴직금/해고/근로시간/연차 공용) — Linear

- **적용 구조**: 헤어라인 테두리 카드, 점 없는 flat 상태 태그(작은 라운드 텍스트 태그, 999px 필 아님), monospace 숫자, 그림자 없음, 마케팅형 대형 히어로 대신 조밀한 유틸리티 헤더.
- **1차 시도 문제(스크린샷 찍기 전 코드 리뷰로 발견)**: `case-ui.css`의 `.case-hero h1`이 `clamp(1.9rem,4.3vw,2.75rem)` + `letter-spacing:-.045em`인 대형 마케팅 히어로 타이포였음 → 체크리스트 4번(헤드라인+리드+버튼 뼈대) 위험. `.case-shell`/`.case-hero`를 축소(h1 1.4rem/line-height 1.35/weight 750, 상단 padding 26px, 모바일 미디어쿼리도 1.3rem으로 일치시켜 축소)한 뒤 재검증.
- **체크리스트**: 5/5 아니오 → **통과**.
  - (1) 필 버튼: kicker 태그는 7px 라운드, 주 CTA 버튼도 9px 라운드 — 999px 필 없음.
  - (2) 배경 블러/그라데이션 원 장식: 없음(순백 배경, 헤어라인 카드).
  - (3) 색사각형+라인아이콘 반복: 이 화면엔 아이콘 자체가 없음(질문 카드는 텍스트+라디오/입력 위주).
  - (4) 헤드라인+리드+버튼+카드그리드 뼈대: 헤드라인 아래 바로 버튼이 오지 않고, 카드도 그리드가 아니라 세로로 쌓인 질문 패널(폼) — 다른 뼈대.
  - (5) 다른 SaaS 템플릿과 구분 안 됨: 도메인 특화 문구("마지막 근무일의 다음 날로 입력", "DB형/DC형" 등)와 조밀한 Linear 톤 레이아웃으로 구분됨.
  - `wage-intake.html`과 `retirement-intake.html` 두 도메인에서 동일 CSS(`case-ui.css`, 서버 injection으로 5개 Case 페이지 전체 공용) 적용을 스팟체크로 확인 — 공용 CSS라 나머지 3개 도메인(해고/근로시간/연차)도 동일하게 적용됨.
- **스크린샷**: `.claude/design-refs/2026-09-07/04-case-wage.png`, `.claude/design-refs/2026-09-07/05-case-retirement.png`
- **시도 횟수**: 2회(코드 리뷰 단계에서 1차 문제 발견 → CSS 수정 → 2개 도메인 스팟체크 스크린샷 통과)
